# 扳手

扳手有三种模式。

1. 扳手
2. 复制粘贴
3. 批量放置

按住 Shift 并滚动鼠标滚轮切换模式。
扳手在主手或副手时均可使用。

## 扳手模式

右键单击节点以打开节点配置。

Shift + 右键单击节点以移除节点。
移除节点会掉落：

1. 节点物品
2. 所有通道中的所有过滤器
3. 所有已安装的升级

## 复制粘贴模式

右键单击节点以将该节点设置复制到扳手剪贴板。

Shift + 右键单击节点以将剪贴板数据粘贴到该节点。

Ctrl + 右键单击节点以将剪贴板数据粘贴到相同类型方块的所有连接节点上（这些方块上必须已附加节点）。

在空气中右键单击打开剪贴板编辑器。

在空气中 Shift + 右键单击发送剪贴板数据的聊天预览。

如果你在副手持有带有剪贴板数据的扳手时放置一个新节点，模组会尝试自动粘贴到该节点。

剪贴板粘贴会应用复制节点中的通道设置、升级和过滤器配置。

## 批量放置模式

此模式允许你一次性放置多个节点。

控制：

1. 右键单击方块：选择或取消选择该方块。
2. Ctrl + 右键单击方块：切换相同类型的连接方块。
   如果单击的方块已被选中，则移除选中的连接方块。
   如果单击的方块未被选中，则添加连接的有效方块。
3. 在空气中右键单击：打开批量放置界面。
4. 在该界面中按下“放置节点”：在本维度所有选中的方块上放置节点。

当你在此模式下持有扳手时，选中的方块会显示橙色轮廓。

批量放置界面显示：

1. 选中方块数量
2. 所需节点数量
3. 所需升级数量
4. 所需过滤器数量
5. 放置可能或受阻的状态标记
6. 所需物品列表，每个物品带有勾选或叉号以及可用/所需数量

如果扳手剪贴板中有一个复制的节点配置，该配置会自动粘贴到每个放置的节点上。
