# 节点详情

本页映射了节点 GUI 中的每一个设置。

通道页面上的顶部控件：

1. 网络名称标签
2. 节点渲染的可见性切换
3. 返回网络选择的更改按钮
4. 从 0 到 8 的通道选项卡

左侧设置面板中的行：

1. 状态
2. 模式
3. 类型
4. 面
5. 红石
6. 分配
7. 优先级
8. 批量
9. 延迟
10. 名称

## 每行的作用

1. 状态切换通道启用/禁用。
2. 模式循环接收端和发送端。
3. 类型循环物品、流体、能量、化学品和魔源（带有升级检查）。
4. 面设置用于提取或插入的能力面。
5. 红石设置运行条件。
6. 分配为发送端选择目标排序。
7. 优先级供优先级分配模式使用。
8. 批量设置每次操作的最大数量。
9. 延迟设置运行之间的刻数。
10. 名称为通道设置自定义标签。

## 限制和特殊情况

1. 优先级被限制在 -99 到 +99 之间。
2. 批量被限制在当前升级等级的上限。
3. 延迟具有来自升级等级配置的最小值。
4. 能量类型强制延迟为 1 刻。
5. 在接收端模式下，分配、批量、延迟行在 UI 中被禁用。

升级槽位是整个节点共享的，不是每个通道单独拥有。

## 有用的输入快捷键

1. 左键向前循环。右键向后循环。
2. 按住 Shift 进行更大的数值步长更改。
3. 双击优先级、批量或延迟以输入数字。
4. 按住 Alt 并单击数值行以跳转到最小值或最大值。

## 过滤器和升级槽位

1. 每个通道有一个 3x3 的过滤器网格。
2. 节点有一个 2x2 的升级网格。

过滤器标签附近的过滤模式按钮切换该通道的任意/全部。

网络选择页面有：

1. 用于新网络的网络名称输入
2. 创建网络按钮
3. 带滚动的现有网络列表
4. 单击条目以加入该网络
