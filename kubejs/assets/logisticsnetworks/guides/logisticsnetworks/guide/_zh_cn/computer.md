# 计算机

计算机是一个可放置的方块，提供一个终端界面，用于监控和管理你的物流网络。

## 打开计算机

右键单击计算机方块以打开终端。计算机会自动检测你物品栏中的扳手并将其加载到驱动器托架中。你的网络会列在左侧的网络目录中。

## 网络目录

左侧面板列出了你拥有的所有网络。单击一个网络以挂载它并查看其详细信息。如果你有很多网络，可以滚动浏览。面板会显示每个网络的名称和节点数量。

## 子系统

选择一个网络后，有两个子系统可用：

### I/O 监视器

I/O 监视器显示所选网络中所有活跃的通道，按通道索引聚合。每个条目显示通道编号、节点数量和资源类型。

单击一个通道条目以打开其吞吐量图表。图表显示传输流的实时时间线（物品/秒、mB/秒、RF/秒等），每秒更新一次。遥测历史记录保存 120 个数据点。

使用类型选项卡（物品、流体、能量、化学品、魔源）来筛选显示的通道类型。

### 节点表

节点表列出所选网络中的所有节点，按标签分组。对于每个节点，你可以看到：

- 节点附加到的方块类型
- 其坐标和维度
- 高亮和设置按钮

**高亮** — 单击节点旁边的高亮指示灯图标，可切换其世界中的发光轮廓，使其易于定位。你也可以同时高亮共享同一标签的所有节点。

**设置** — 单击设置图标以远程打开该节点的配置界面。

**可见性** — 使用顶部的显示/隐藏按钮，批量切换网络中所有节点的渲染可见性。
